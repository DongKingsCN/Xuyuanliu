# 许愿柳
**注：由github.com/ns2250225/xuyuanliu的源代码编译而成的，开箱即用无需二次编译**

**部署教程**
在Releases下载编译好的zip文件上传至服务器即可。

**使用说明**
1. 点击“开始许愿”。
1. 输入愿望并确认规则。
1. 持续按住许愿柳，直到进度达到 100%。
1. 查看愿望完成结果。
1. 复制或下载带二维码的愿望分享卡片。
